# 우리집 찾기 — 부동산 매물 검색·시세·계산기

설치 없이 브라우저에서 여는 부동산 웹앱입니다.

## 실행

`index.html`을 브라우저로 열면 됩니다. 서버가 필요 없습니다.

## 기능

- **매물 검색**: 키워드·지역·유형·거래종류(매매/전세/월세)·가격·면적 필터, 정렬
- **매물 등록/수정/삭제**: 브라우저(localStorage)에 저장, JSON 백업 저장·불러오기
- **시세 요약**: 지역·유형별 평균 평당 매매가/전세가, 전세가율
- **계산기**
  - 중개보수 (주택, 2021.10 개정 상한요율, 월세 환산 포함)
  - 취득세 (주택 매매, 1~4주택·조정대상지역, 지방교육세·농어촌특별세)
  - 대출 이자 (원리금균등·원금균등·만기일시, 연도별 상환표)

계산 결과는 참고용입니다. 감면·특례 등 예외는 반영하지 않았습니다.

## 구조

```
index.html        화면
css/style.css     스타일 (라이트/다크 모드)
js/calc.js        계산 로직 (브라우저·Node 공용)
js/app.js         매물·검색·시세·계산기 화면 로직
tests/            계산 로직 테스트
```

## 테스트

```
node --test tests/*.test.js
```
