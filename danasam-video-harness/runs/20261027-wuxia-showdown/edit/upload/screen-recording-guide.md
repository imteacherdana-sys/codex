# Higgsfield 화면 녹화 촬영 가이드 · 무협 쇼다운

브리프 필수 항목 세 가지를 이 녹화 하나로 채웁니다.

1. Higgsfield **웹사이트** 안에서 생성하는 과정을 화면으로 보여주기
2. **모델 선택기**에서 모델을 바꾸는 장면과 **프롬프트**가 화면에 보이기 (기다리는 구간만 빨리감기 가능)
3. "8개 모델 모두 Higgsfield에서, **같은 프롬프트와 같은 설정**으로 돌렸다"고 말하기

예상 시간: 준비 10분 + 녹화 20~30분 · 편집에서 약 60초로 줄여 씁니다.

---

## 0. 결정할 것 하나: 다시 생성할까, 기록을 보여줄까

지금 영상 속 결과 40개는 단아쌤 Higgsfield 계정으로 만든 실제 결과지만, 웹 화면이 아니라 연동 도구로 생성했습니다.
브리프의 "웹사이트에서 화면으로 생성"을 확실히 지키려면 아래 **추천 방식**을 권합니다.

| 방식 | 하는 일 | 크레딧 | 영상에서 말할 것 |
|---|---|---|---|
| **추천** | 시험 1(장풍)만 웹에서 8개 모델로 다시 생성하며 녹화 + 나머지 시험은 생성 기록(History) 화면을 녹화 | 약 230 | "시험 1은 화면 그대로 다시 돌려 보여드리고, 나머지는 같은 계정의 생성 기록입니다" |
| 최소 | 생성 기록 화면만 녹화 + 새 생성은 Kling 4.0 한 번만 시연 | 4 | "결과는 모두 이 계정의 생성 기록입니다" |

- 다시 생성한 결과는 처음 결과와 다르게 나옵니다. **영상 본편은 첫 결과 그대로 두고**, 녹화본은 "작업 과정"으로만 씁니다.
- 브리프 해석이 애매하면 캠페인 담당자에게 "API로 만든 결과 + 웹 화면 녹화" 조합이 괜찮은지 한 번 물어보는 것도 방법입니다.

## 1. 준비 (녹화 전 10분)

- [ ] **PC 브라우저**로 higgsfield.ai 접속 (Higgsfield는 모바일 앱이 없습니다. 앱스토어의 비슷한 이름 앱은 관련 없음)
- [ ] 녹화 설정: **1920×1080 · 30fps**, 컴퓨터 소리는 끄고 녹화 (멘트는 나중에 따로 녹음)
- [ ] 브라우저 확대 **110~125%** (프롬프트 글자가 영상에서 읽히게)
- [ ] 북마크바 숨기기, 다른 탭 닫기, 메신저·메일 알림 끄기
- [ ] 화면에 나오면 안 되는 것 확인: 이메일 주소, 결제 정보, **캠페인 브리프·크리에이터 대시보드 화면**
- [ ] 메모장에 프롬프트 5개 준비 (`upload-kit.md` 설명란의 프롬프트 전문을 그대로 복사, **한 글자도 고치지 않기**)
- [ ] 바탕화면에 인물 사진 2장: `characters/seo-sojeo.png`, `characters/gwi-gongja.png`
- [ ] 크레딧 잔액 확인 (추천 방식이면 약 230 필요)

**공통 설정값** (모든 모델 동일): 길이 **8초** · 비율 **16:9** · 화질 **720p** · 소리 켜기(지원하는 모델만)
→ MiniMax H3는 2K만 선택됩니다. 이 화면을 꼭 녹화해 두세요.

## 3. 녹화 위에 넣을 멘트 (화면 녹화 구간 내레이션)

브리프의 "영상에서 직접 말하기" 항목입니다. 녹음할 때 아래 문장을 그대로 읽어주세요. 3~5번과 8~9번은 화면 녹화 자리의 자막 그대로이고, 1·2·6·7번은 다른 장면에도 나오지만 녹화 화면 위에서 한 번 더 말하는 문장입니다.

1. 여덟 개 모델 모두 Higgsfield에서 돌렸습니다.
2. 모델마다 똑같은 프롬프트와 똑같은 설정을 넣었습니다.
3. Higgsfield에서는 모델 선택기에서 모델만 바꾸면 됩니다.
4. 프롬프트는 그대로 남아 있어서
5. 여덟 번 복사할 필요가 없습니다.
6. MiniMax H3는 2K만 지원해서 화질이 다릅니다.
7. Gemini Omni 1.1은 인물 사진 Reference를 두 번 거절했습니다.
8. 지금 Kling 4.0 출시 할인도 진행 중입니다.
9. 링크는 설명란 맨 위에 있습니다!

(추천 방식으로 찍었다면 추가) 시험 1은 화면 그대로 다시 돌려 보여드리고, 나머지는 같은 계정의 생성 기록입니다.
