# 단아쌤 블럭 쇼츠

엔진: `danasam-video-harness/block-shorts/block_shorts.py` (설명표 JSON → 렌더 → 소리 섞기 → MP4)
예시: `danasam-video-harness/runs/20261027-wuxia-showdown/shorts/` (`gen_specs.py`가 본편 편집표에서 설명표 3개를 만든다)

## 1. 스타일 원칙 (레퍼런스에서 가져온 원리 + 블럭 옷)

참고한 편집 원리 (에디터 노션 「클로드코드로 영상 편집 + 모션그래픽」): 하드컷 대신 이동·변형으로 잇기, 대사 한 줄마다 화면 사건 하나, 말하는 영상이 작은 창으로 줄었다 돌아오기, 얼굴·입은 절대 가리지 않기, 색 3~4개·서체 2개로 통일. 장면 순서·문구·로고는 가져오지 않는다.

그 위에 입힌 '블럭' 옷:

| 요소 | 규칙 |
|---|---|
| 색 | 종이 `#fff7e8` 바탕 + 점 무늬, 블럭은 노랑 `#ffd43b` · 민트 `#63e6be` · 하늘 `#74c0fc` · 산호 `#ff8787` · 라일락 `#b197fc`, 선은 먹색 `#1d1b2e` |
| 블럭 | 테두리 7~8px 먹색, 모서리 26~30px, 그림자는 흐림 없이 오른쪽 아래로 10~12px (장난감 블럭 두께) |
| 서체 | 블럭·자막 Jua (둥근 한글, OFL), 숫자 Pretendard Black |
| 움직임 | 등장은 `back.out`(통통) 또는 `bounce.out`(떨어져 쌓임), 살짝 기울기(±2~6°), 정지할 땐 천천히 흔들기. 매끈한 페이드만 쓰지 않는다 |
| 소리 | 직접 합성한 뽁(pop) · 뽀잉(boing) · 딸깍(brick) · 짠(tada) · 클릭. 블럭 하나에 소리 하나 |

## 2. 화면 사건 (설명표 `visual.type`)

| type | 언제 | 모습 |
|---|---|---|
| `title` | 첫 1~3초 훅 | 한 글자씩 색 블럭이 위에서 떨어져 2줄로 쌓임 (`rows: ["장풍","대결"]`, 줄당 2~4글자) |
| `clip` | 모델 결과·예시 영상 | 영상이 블럭 창으로 통통 튀어 들어옴. `label`(왼쪽 위 이름표) · `badge`(오른쪽 위 가격) · `stamp`(가운데 도장, 예: "단야?") |
| `grid` | 여러 결과 한눈에 | 2×4 블럭 타일이 차례로 '뽁'. 번호 블럭. `winner`로 하나 강조 |
| `bars` | 숫자 비교 | 막대가 블럭(`unit` 크레딧 = 블럭 1개)을 하나씩 끼우며 자람. 강조 항목은 노랑 + 들썩 |
| `sticker` | 한 줄 결론·CTA | 큰 말풍선 블럭이 회전하며 붙고 흔들림 |
| `full` | 완성 영상 감상 | 전체 화면. 얼굴 숨김, `audio: true`면 클립 소리 |

얼굴 창: `title`·`sticker`는 전체 화면, `clip`·`bars`는 오른쪽 위 둥근 블럭 창(pip), `grid`·`full`은 숨김. 바뀔 때 통통 튀며 줄었다 커진다.

자막: 한 줄 약 12자, 두 줄씩. 단어마다 흰 블럭, `highlight_words`에 든 단어는 노랑 블럭. 위치는 화면 위에서 1150px (쇼츠 아래쪽 UI 가림 구역 위).

## 3. 만드는 순서

1. **목소리 조각 고르기**: 본편 편집표가 있으면 그 편집점(말 절음·중복 제거, 무음에 맞춘 경계)을 그대로 쓴다. 새 녹화면 먼저 받아 적고(faster-whisper), 소리 덩어리별로 다시 받아 적어 말 절은 곳을 찾는다 (본편 `tools/burst_check.py` 방식).
2. **설명표 쓰기**: 쇼츠 하나 = beat 6~8개, 35~50초. 첫 beat는 `title`(질문형 훅), 마지막은 `sticker`(본편 유도). beat = `{"voice": [[시작,끝],...], "caption": "...", "visual": {...}}`. 목소리 없이 영상만 보여줄 땐 `"voice": [], "min": 초`.
3. **미리보기**: `python3 block_shorts.py spec.json --preview` 후 Playwright로 몇 초씩 찍어 겹침·가림을 먼저 본다 (`seek` 후 스크린샷).
4. **렌더**: `python3 block_shorts.py spec.json` → `spec과 같은 폴더/<id>.mp4` (1080x1920 30fps, -14 LUFS).
5. **검수**: 자막과 말이 맞는지, 블럭이 얼굴·입을 가리지 않는지, 아래 35% 구역에 읽어야 할 글자가 없는지.

## 4. 하지 말 것

- 얼굴·입 가리기, 화면 아래 35%에 중요한 글자 두기
- 한 beat에 사건 두 개 이상 (블럭이 많아지면 귀여움이 아니라 산만함)
- 이모지 글자 (Jua에 없음), 남의 로고·캐릭터·영상
- 다른 사람 사진을 합성하거나 인물 얼굴을 바꾸기
