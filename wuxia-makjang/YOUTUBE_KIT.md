| 타임 | 챕터 | 화면 | 브리프 대응 |
|---|---|---|---|
| 00:00 | 인트로 | 완성본 하이라이트 → 단아쌤 | 훅 |
| 00:40 | Higgsfield · Kling 4.0 소개 | **공식 Media Kit** + 화면녹화 | ❗ 30초 = Kling 3.0의 2배 / ❗ 3개 모드 한곳 + Generate 버튼 크레딧 (카메라 앞 멘트) |
| 01:40 | References | 레퍼런스 ↔ 결과 나란히 | multi-reference video, 계획과 결과 비교 |
| 03:00 | 30초 한 컷 | 프롬프트 화면녹화 → **30초 전체 재생** | 30 second AI video, 결과를 자르지 않고 재생 |
| 04:20 | Frames | 키프레임 ↔ 결과 장면 나란히 | keyframes AI video |
| 05:30 | Edit video | 원본 · 레퍼런스 · 결과 3칸 | AI video editing, 바꾸지 않은 부분도 확인 |
| 06:30 | 더빙·입모양 | 파형 비교 | 대사 프롬프트 → 입모양 → 더빙 맞추기 |

| 08:10 | 시도 횟수·크레딧·한계 | 표 | 여러 번 시도한 사실을 솔직하게 |
| 08:50 | 아웃트로 | 단아쌤 | CTA |

## 5. 업로드 체크리스트

- [ ] 유튜브 스튜디오 → 「유료 프로모션 포함」 체크
- [ ] 「변경되거나 합성된 콘텐츠」(AI 생성) 표시
- [ ] 설명란 1~2번째 줄에 광고 표기 + UTM 링크 (더보기를 누르지 않아도 보이는지 모바일로 확인)
- [ ] 고정댓글 등록 후 **고정** 클릭
- [ ] 챕터가 인식되도록 첫 타임스탬프가 `00:00`인지 확인 (최소 3개, 각 10초 이상)
- [ ] 영상 길이 6분 이상
- [ ] 화면녹화에 Higgsfield 웹사이트에서 Kling 4.0 생성 과정이 보이는지, 세 모드 중 2개 이상인지
- [ ] 카메라 앞에서 '30초 = Kling 3.0의 2배', '3개 모드 한곳 + Generate 버튼 크레딧'을 말했는지
- [ ] 4K·HDR·2분 연장을 언급하지 않았는지
