# 모션그래픽 완전정복 — 내레이션 대본 (A안, 얼굴 없음)

목소리: 단아쌤 내레이션-1 (Higgsfield seed_audio, element `c103b1d0-…`), 48kHz wav.
비트 하나 = 음성 파일 하나. 화면 글자는 이 대본에 나온 말만 쓴다.

| 비트 | 장면 | 내레이션 |
|---|---|---|
| B01 | hook | 화면에 자막 한 줄이 툭 떴어요. 틀린 건 없는데, 어딘가 밋밋하죠? |
| B02 | hook | 오늘은 이 자막 한 줄을, 원리 네 가지로 살려볼게요. |
| B03 | timing | 첫 번째는 타이밍이에요. 글자를 한꺼번에 띄우지 말고, 조금씩 시간차를 두세요. |
| B04 | timing | 같은 문장인데, 벌써 읽히는 순서가 생겼죠? |
| B05 | easing | 두 번째는 이징이에요. 똑같은 속도로 움직이면 로봇처럼 보여요. |
| B06 | easing | 빠르게 출발해서 천천히 멈추면, 훨씬 자연스러워져요. |

| B10 | compare | 처음 자막과 지금 자막, 나란히 볼까요? 문장은 하나도 안 바뀌었어요. |
