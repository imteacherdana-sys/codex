# 피드백 규칙 장부

사람이 준 수정 지시는 여기에 규칙으로 남겨 다음 영상부터 자동 적용한다 (HARNESS.md §0-2, S13).
규칙은 지우지 않는다. 더 이상 쓰지 않으면 `상태`를 `폐기`로 바꾸고 이유를 적는다.

| ID | 출처 | 규칙 | 적용 단계 | 검사 방법 | 상태 |
|---|---|---|---|---|---|
| EDIT-001 | danasam-tech-explainer | 무음은 `-60dB`·0.3초 기준으로 찾고, 첫소리 앞 0.12초·어미 뒤 0.3초를 남긴다. `-45dB` 기준 금지 | S7 | 비트 시작·끝 200ms 파형에 음성 에너지가 잘리지 않았는지 | 사용 |
| MOTION-001 | danasam-tech-explainer | 최상위 배경에 `wordBreak: keep-all` | S8 | 그리드에서 단어 중간 줄바꿈 0개 | 사용 |
| MOTION-002 | danasam-tech-explainer | 실제 제품 UI를 모션으로 재현하지 않는다 | S3, S8 | RECORD여야 할 비트가 PIP인지 검사 | 사용 |
| MOTION-003 | danasam-tech-explainer | 화면 글자·자막에 TTS용 한글 표기(엠피포 등)를 남기지 않는다 | S8, S9 | 자막·props 텍스트에서 표기 사전 검색 | 사용 |
