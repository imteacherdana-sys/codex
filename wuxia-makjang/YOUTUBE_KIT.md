## 2. 영상 구성안 (약 9분)

| 타임 | 챕터 | 화면 | 내용 |
|---|---|---|---|
| 00:00 | 인트로 | **완성본 하이라이트 10초** → 단아쌤 | 쌍둥이 언니 등장 장면으로 훅. "오늘 이걸 AI로 만들어 보겠습니다" |
| 00:40 | 힉스필드 소개 | **공식 Media Kit**(로고·소개 영상) | 힉스필드가 어떤 서비스인지, 왜 클링 4.0을 여기서 쓰는지 |
| 01:30 | 캐릭터 시트 | 화면녹화 | 인물 5명 시트 생성, 쌍둥이는 레퍼런스로 같은 얼굴 만들기 |
| 02:40 | Kling 4.0 열기 | **화면녹화** (README §4 시퀀스) | Video → Kling 4.0 → 모드 4가지 소개 |
| 03:30 | 멀티 레퍼런스 | 화면녹화 | Reference to Video로 시트 3장 넣고 C1 생성 |
| 04:30 | 키프레임 | 화면녹화 | Image to Video에 시작·끝 프레임을 넣어 C3→C4 연결 컷 |
| 05:20 | 30초 vs 15초 | 결과 비교 | 30초 한 번에 뽑기 vs 15초×4 나누기, 장단점 |
| 06:10 | AI 영상 편집 | 화면녹화 | Video Edit 모드로 마음에 안 드는 부분 수정 + 자막·TTS 입히기 |
| 07:00 | 완성본 감상 | 60초 풀버전 | 「혈풍혼례」 1화 |
| 08:00 | 비용·한계 | 단아쌤 | 크레딧 정리, 잘 안 되는 것(손, 빠른 액션, 한글 입모양) 솔직하게 |
| 08:40 | 아웃트로 | 단아쌤 | 시그니처 클로징 |

> Media Kit 에셋(로고, 공식 소개 클립)은 크리에이터 대시보드에서 내려받아 00:40 구간과 썸네일에 사용하시면 됩니다.

## 5. 업로드 체크리스트

- [ ] 유튜브 스튜디오 → 「유료 프로모션 포함」 체크

- [ ] 챕터가 인식되도록 첫 타임스탬프가 `00:00`인지 확인 (최소 3개, 각 10초 이상)
