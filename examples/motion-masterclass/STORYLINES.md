# 모션그래픽 완전정복 — 스토리라인 3안

- 형식: HyperFrames, 1920×1080, 30fps, 60~90초
- 디자인: 단아쌤 Tech Dark (남색 격자 배경, Pretendard, 보라 + 라임 강조)
  HyperFrames의 기본 금지 목록(어두운 남색 배경, 네온 글로우, 보라 그라데이션, 알약 모양 칩)은
  "브랜드가 원래 쓰는 재료면 그 방식대로만 허용"이므로, 단아쌤 브랜드 규칙 안에서만 쓴다.
- 레이아웃: 하네스 `design/layout.md`. PIP 장면은 오른쪽 아래 400×500 얼굴 자리를 비운다.
- 한 가지 메시지: **모션그래픽은 "무엇이, 언제, 어떻게" 움직일지 정하는 일이다.**

---

## A. 밋밋한 자막 한 줄이 살아나기까지 (추천)

추천 이유: 시청자가 매일 보는 "자막 한 줄"이 주인공이라, 원리 4개가 하나의 결과물 위에서 바로 보인다.

- **장치·형식:** 하나의 예시를 끝까지 고친다 (worked example) × 한 화면이 계속 다시 짜인다 (one frame that rebuilds)
- **보이는 것:** 화면 가운데 그냥 툭 떠 있는 자막 「모션그래픽 완전정복」. 원리를 하나 배울 때마다 바로 그 자막이 한 단계씩 좋아진다. 마지막에는 처음과 같은 문장이 완전히 다른 느낌으로 등장한다.
- **첫 2초:** 아무 움직임 없이 한 번에 툭 나타나는 자막, 그 위로 코랄 도장 「밋밋함」.
- **비트:** 훅(밋밋한 자막) → 타이밍(글자를 시간차로) → 이징(직선 vs 감속 곡선 나란히, 그래프가 그려짐) → 위계(키워드 하나만 라임) → 전환(자막이 다음 장면의 문이 됨) → Before/After 나란히 → 한 줄 정리 「움직임은 순서다」 → 로드맵(다음 편 4가지)
- **룩:** Tech Dark 격자, Pretendard 800, 장면마다 강조 단어 하나만 라임
- **소리:** 내레이션 없이 큰 문장으로 진행. 음악은 소스가 생기면 추가 (지금은 무음)

## B. 이징 그래프 위를 달리는 공

- **장치·형식:** 사물이 곧 설명이다 (the object is the explanation) × 한 세계를 날아다니는 카메라
- **보이는 것:** 화면 가득한 이징 그래프. 공 하나가 곡선을 따라 움직이고, 카메라가 그래프 위 점 4개(타이밍·이징·위계·전환)를 차례로 들른다. 곡선 모양이 바뀌면 공의 움직임도 바로 바뀐다.
- **첫 2초:** 같은 거리를 가는 공 두 개. 하나는 로봇처럼, 하나는 자연스럽게.
- **비트:** 공 두 개 비교 → 그래프로 줌아웃 → 점 4개 순회 → 공이 자막으로 변신 → 한 줄 정리
- **룩:** Tech Dark 위에 그래프 선은 흰색, 공은 라임
- **소리:** 공이 도착할 때마다 작은 효과음 (소스 필요)

## C. 1초를 30장으로 (가장 과감한 안)

- **장치·형식:** 숫자 하나가 무게를 갖는다 (a number lands) × 끝없는 줌 (endless zoom)
- **보이는 것:** 「1초」라는 글자를 확대하면 필름 30장이 나오고, 한 장을 확대하면 그 안의 키프레임, 키프레임을 확대하면 이징 곡선이 나온다. "모션 = 30장의 그림을 정하는 일"을 몸으로 느끼게 한다.
- **첫 2초:** 화면 가득한 「1초」, 카메라가 '1' 속으로 뛰어든다.
- **비트:** 1초 → 30프레임 필름 → 키프레임 2개 → 사이를 채우는 곡선 → 다시 줌아웃해서 완성된 자막
- **룩:** Tech Dark, 필름 스트립은 보라, 현재 프레임만 라임
- **소리:** 프레임이 넘어갈 때 틱 소리 (소스 필요)
