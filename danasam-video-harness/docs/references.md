# 레퍼런스 분석 요약 (2026-10-26 확인)

두 영상 모두 원본 파일은 받지 못했다. YouTube가 클라우드 환경의 다운로드를 막아서,
AI 장면 분석(장면별 자막·화면 설명)과 썸네일·저해상도 프레임으로 분석했다. 색·폰트 수치는 추정이다.

## 1. 커리어해커 알렉스 — 「영상 하나에 30시간 작업하던 일을 전부 자동화한 방법」

- URL: https://youtu.be/ESnqYamB_NI · 확인 범위: 0:00~14:31 장면 분석 전체

**핵심 주장**
1. 라이브 1편 → 롱폼 5편 + 쇼츠 약 20편. 편집 부담이 사라지니 "재료(메시지)를 만드는 것"에 집중하게 됐다.
2. 남의 롱폼이나 X(트위터) 글을 그대로 번역하지 않는다. Claude가 질문하고 본인이 답하는 **인터뷰**로 자기 관점을 더해 2차 콘텐츠를 만든다.
3. 공통 파이프라인: **기획/리서치 → 대본 → 보이스 → 모션/편집 → QA/검수 → 썸네일/패키징 → 업로드/기록**.
4. 스킬로 만든 것: 라이브 컷 편집, 어디를 자를지 LLM이 판단, 자체 디자인 시스템("Bolt Kinetic"), 글자 배치 규칙, 차트·모션 빈도 규칙.
5. QA는 AI끼리 교차 검수한다 (Claude가 쓴 것을 Codex가 보고, 반대로도).
6. **Human-on-the-loop**: 승인 대기가 쌓이면 사람이 병목이 된다. 피드백마다 스킬·규칙·하네스로 만든다.
   크레딧 상한(쇼츠 500, 롱폼 1,500)과 캐릭터 생성 후 확인 같은 체크포인트만 남긴다.
7. 본인 분석: 26,000회 영상에서 **본인이 말하는 구간에서 시청자가 이탈**했다 → 말만 하는 구간을 줄여야 한다.

**화면 형식**
- 흰 배경 흐름도에서 말하는 단계 박스만 순서대로 강조한다.
- 검은 화면의 "실습 프롬프트 n/7" 카드가 파트마다 나온다 (시청자가 캡처해서 Claude에 붙여 넣게 한다).
- 큰 숫자 카드 ("99.8%").
- 얼굴은 풀화면 클로즈업만 쓰고, PiP는 쓰지 않는다.

**이 하네스에 반영한 것:** 파이프라인 7단계(HARNESS §1), 관문 3개와 자동 정지 조건(§3·§6), 피드백 규칙 장부, 교차 검수, 실습 프롬프트 카드(P8), 흐름도 하이라이트(P9), FACE 20초 제한(SCRIPT-003).

## 2. 코드깎는노인 — 「최신 AI 모델들의 미적 감각 비교」

- URL: https://youtu.be/Y5yrM-9sCvQ · 확인 범위: 0:00~1:57 장면 분석 + 썸네일

**연출 원리:** 고정 무대(책상 3대), 스포트라이트 조명, 출연자별 고유색, 비우기 강조, 드로우온(점→선→면), 결과물 위 코드 오버레이 + 라벨, 수식 카드("그림 = 코드"), 타임라인 시각화, 코르크보드 로드맵 + "Round 01/06" 카드, 3박자 키워드.

**구조:** 훅(출연자) → Before/After → 방법 → 개념 3단 → 로드맵 → 라운드 반복. 2분 안에 "무엇을·왜·어떻게·몇 판"을 다 알려준다.

**썸네일:** 포디움 3개 위 3D 로고 + 고유색 림라이트, 질문형 3D 카피("셋 중 하나만 쓴다면"), 강조어 1개만 골드.

**이 하네스에 반영한 것:** 모션 원리 P1~P7, 컴포넌트 신규 9종, 도입부 0:00~2:00 표준 구성, subjectColors 토큰.
**따라 하지 않는 것:** 책상·조명 세트 디자인 자체, 채널 고유의 3D 로고 처리.
