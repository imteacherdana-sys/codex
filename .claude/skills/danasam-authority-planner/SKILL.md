# 단아쌤 권위형 롱폼 기획 (세진 PD 방식)

이 스킬은 **기획서**를 만든다. 제작 단계(촬영·편집·모션)는 `danasam-video-harness/HARNESS.md`가 맡고,
기획·검수 계약은 노션 「스킬｜세진 PD 영상 제작 하네스 v1.2」를 따른다. 이 문서는 그 위에 **단아쌤 채널의 기획 공식**을 더한다.

원형이 된 세진 PD 기획서 4편 (노션): 클로드 스킬(260612), 클로드 디자인(0715 촬영), 제미나이 옴니(260529), 바이브코딩.

---

## 1. 절대 원칙 4가지

1. **대상은 일반 대중이다.** 생산성 AI에 관심 있는 직장인·대학생·공무원·자영업자·5060까지. 셀러(쇼핑몰·스마트스토어) 중심 예시를 쓰지 않는다. 예시를 고를 때 "이 사람이 매주 반복하는 일인가"로 고른다.
2. **쉬운 것 → 깊은 것.** 첫 10분은 비전문가도 따라오는 비유와 결과 화면. 뒤로 갈수록 실무 디테일·한계·검증. 전문 용어는 처음 나올 때 쉬운 말로 먼저 푼다 (예: 디자인 시스템 = "우리 회사 스타일 묶음").
3. **권위는 주장하지 말고 보여준다.** "제가 교수라서"가 아니라, 교수·대표로서 실제로 쓰는 장면, 학생에게 가르친 결과, 남들이 놓친 해석(여론 반전 분석), 사전 검증과 정직한 한계로 증명한다.
4. **사실은 확인된 것만.** 기능·가격·출시일은 공식 출처로 확인한 "확정 팩트 표"에 있는 표현만 쓴다. 해외 반응은 "여론"으로 인용하고 승패를 단정하지 않는다. 숫자를 말할 때는 화면 하단에 출처 자막. 단아쌤 경력·수치는 **본인이 확인해 준 것만** 쓴다.

## 4. 구간별 화면 연출 (어떻게 보여줄까)

`HARNESS.md`의 레이아웃(FACE / PIP / RECORD / CARD / END)과 템플릿 팩(`danasam-video-harness/templates/`)으로 만든다.

| 구간 유형 | 화면 | 쓰는 템플릿·모션 |
|---|---|---|
| 결과 선공개 | 결과 화면 풀스크린 → 단아쌤 얼굴로 컷 | 결과물에 **푸시인 줌**(1.0→1.15, 0.6s), 핵심 부분 손그림 동그라미 (`hw-callout-circle`) |
| 단아쌤 소개 | 얼굴 + 이름·직함 카드 | **권위 카드**: 이름 / 직함 / 한 줄 이력, 라임 밑줄 (`lt-kicker-name` 확장) |
| 이론 설명 | 얼굴 PiP + 흐름도·비유 그래픽 | `FlowSteps`, `DrawOn`, `EquationCard`, 화이트보드 (`whiteboard-ink`) |
| 최신 뉴스 | X·레딧 게시물 카드 | **뉴스 카드**: 게시물 캡처를 카드로 띄우고 날짜·출처 자막, 카드 사이 **카메라 패닝**. 실제 캡처만 쓰고 재현하지 않는다 |
| 레퍼런스 영상 | 해외 사례 클립 (출처 표기) | 클립을 기울어진 화면에 넣고 **줌인 → 핵심 장면 정지 → 동그라미**. 가능하면 "직접 해봤다" 재현본과 좌우 비교 (`before-after-wipe`) |
| 푸티지 깔기 (B-roll) | 단아쌤 목소리 위로 작업 장면·화면 녹화·이미지 | 켄번즈(느린 줌·패닝), 사진 카드 드롭 (`image-drop`), 20~30초 이상 말만 이어지지 않게 |
| 시연 | 화면 녹화 + 얼굴 PiP | 클릭 지점으로 **자동 줌인**(1.0→1.6), 입력창은 `chat-claude` / `chat-chatgpt` 예시 화면은 설명용으로만, 실제 시연은 녹화 |
| 트랩 (첫 실패) | 실패 결과 화면 | 코랄 도장 "어색함" + 흔들림 0.2s, 고친 뒤 같은 구도로 라임 체크 |
| 한계 | 얼굴 풀화면 | 그래픽 최소화, 진정성 |
| 아웃트로 | 3줄 요약 카드 → END | `marker-checklist-card`, `EndCard` |

**모션 업그레이드 규칙 (화려함은 카메라에서):**
- 장면마다 카메라 동작 하나: 푸시인 / 풀아웃 / 패닝 / 휩팬 / 펀치인 중 하나를 고른다. 같은 동작을 연속 두 번 쓰지 않는다.
- 줌은 `scale` 1.0→1.08~1.6, 0.4~0.8s, `power2.inOut`. 결과 공개·핵심 숫자·클릭 지점에서만 크게.
- 전환 3~5종을 섞는다 (카드 플러드, 매치컷, 휩, 블러 스왑). 하드컷은 전체의 1/3 이하.
- 그래픽은 장면당 강조 하나 (라임). 글로우·파티클로 화려함을 대신하지 않는다.

## 5. 권위 체크리스트 (PD 검수 때 함께 본다)

- [ ] 첫 90초 안에 단아쌤이 누구인지(직함·하는 일) 사실로 나왔다
- [ ] "가르친 경험" 또는 "실무에서 쓰는 장면"이 하나 이상 있다 (실제 있었던 일만)
- [ ] 시청자의 반론 2개를 먼저 말했다
- [ ] 남들이 놓친 해석이 하나 있다 (여론·공식 발표를 넘어서는 관점)
- [ ] 첫 실패(트랩)를 숨기지 않고 고치는 과정을 보여줬다
- [ ] 솔직한 한계 3개
- [ ] 모든 수치에 출처, 미확인 수치 0개
- [ ] 셀러 전용 예시 0개, 직장인·대학생·일반인 예시가 섞여 있다

## 6. 쓰는 순서

1. 주제와 촬영일·길이를 받는다. 단아쌤 경력 중 화면에 쓸 수 있는 사실을 확인한다 (모르면 묻는다).
2. 공식 출처로 확정 팩트 표를 만든다. X·레딧 반응과 국내·해외 레퍼런스 영상을 찾고 표로 정리한다 (본 영상은 "제목·설명 기반"인지 "내용 확인"인지 표시).
3. 콘셉트 한 줄 + 제목 3종 + 라이트닝 데모 후보를 먼저 보여주고 방향을 확인받는다 (하네스 H1).
4. 상세 스크립트를 §3 구조와 §4 화면 연출 열까지 채워 쓴다.
5. 독립 PD 검수(세진 v1.2 §8 + §5 권위 체크리스트) 후 노션에 저장한다.
